# allopep
AlloPep: A Pipeline for De Novo Design of Allosteric Peptides

## Installation
```
bash install.sh
```

run the following command from the allopep.py dictory

## Running
```
python allopep.py input/structure.pdb
```
## Output

Please note the the structure.pdb in output file is create by APOP after removing water and hetero atoms.
